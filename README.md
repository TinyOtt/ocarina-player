# Ocarina Player

3D ocarina player/composer with sheet-music import, follow mode and live pitch listening.

- **Android app:** download `OcarinaPlayer.apk` from the *latest* release and open it on your phone to install (allow installs from your browser when asked).
- **Web version:** enable GitHub Pages (Settings → Pages → Source: GitHub Actions) and it is published from `web/`.
- **v3 (redesigned web version):** published next to it at `/v3/` (from `web/v3/`). Same features, new interface; the Android app still uses the current version.

Every push to `main` rebuilds both.
